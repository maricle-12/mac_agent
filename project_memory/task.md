# 项目记忆系统说明

本目录是项目的长期记忆，用于让任何后续开发者 / AI Agent 在几分钟内理解项目状态并继续工作。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `status.md` | 当前进度快照：已完成什么、当前状态、下一步、风险与阻塞 |
| `decision.md` | 长期决策记录：已确定的技术选型、被否决的方案、不可随意推翻的原则 |
| `Readme_agent.md` | 项目地图：目标、技术路线、目录职责、推荐阅读顺序 |
| `task.md` | 本文件：记忆系统自身的说明与维护规则 |

## 推荐阅读顺序

1. `status.md` —— 先看最新状态。
2. `decision.md` —— 改动方向或做设计选择前必读。
3. `Readme_agent.md` —— 需要整体架构背景时阅读。
4. `task.md` —— 仅在维护记忆系统时阅读。

## 维护规则

- 状态变化 → 更新 `status.md`
- 长期技术/方法决策或被否决路线 → 更新 `decision.md`
- 项目结构、模块、工作流变化 → 更新 `Readme_agent.md`
- 记忆系统本身变化 → 更新 `task.md`

记忆更新属于产生该变化的任务本身，不作为额外请求。

## 禁止写入的内容

- 大段代码、原始日志、一次性命令输出
- 真实 API Key 或任何密钥
- 与后续工作无关的临时细节
